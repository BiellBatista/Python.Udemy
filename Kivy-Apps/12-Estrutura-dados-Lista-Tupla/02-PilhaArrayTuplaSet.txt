Lista (para criar uma basta usar um par de colchetes [])
    1 - Estrutura mutável cuja a ordem natural é estabelecida pela odem de entrada
    2 - Novos itens sempre serão adicionados após o último item da lista
    3 - O primeiro item adicionado a lista sempre será o primeiro elemento da estrutura

Pilha
    1 - É um conjunto de elementos adicionados um sobre o outro
    2 - O último elemento a entrar será o primeiro a sair
    3 - O primeiro elemento a entrar será o último da lista

Array
    1 - É um conjunto de elementos finitos e definidos na sua declaração
    2 - O índice 0 é o primeiro elemento da lista
    3 - O índice do último elemento é "total_de_itens-1"

Tupla
    1 - É uma lista declarada como constante
    2 - Não é possível adicionar, remover, alterar elementos (ou seja, não é mutável, mas sim imutável)
    3 - Toda tupla será um conjunto de objetos também imutáveis

Set
    1 - Estrutura de dados semelhante a uma lista
    2 - Tem como princípio conter uma lista de valores diferentes
    3 - É uma lista sem itens repetidos

Dicionário
    Estrutura na qual cada item possui uma chave única e que pode ser de qualquer tipo
    Não aceita dois elementos com a mesma chave

Árvore
    1 - Raiz - elemento pertecente ao nível um. Toda árvore terá sempre uma única raiz.
    2 - Nó/Filho - elemento que foi adicionado a outro item
    3 - Nível - propriedade que indica quantos nós estão de um filho
